After a stint on Hashnode, the blog now lives here, in the same repo as the rest of the site. The trigger was practical — Hashnode's GraphQL API moved behind a paywall — but the upshot is one I would've made anyway: every post is a file in this repo, every edit is a commit, and there's no platform between me and the writing.

## Why move

Hashnode is a good product. But a personal site should not depend on a third-party platform to display its own writing. Two things tipped it over for me:

1. The GraphQL API I was using to power this section started returning HTML instead of JSON.
2. I want full control over rendering — typography, code blocks, the table of contents you're using right now.

## How it works

Posts live under `content/blog/YYYY/MM/*.mdx`. The frontmatter is small on purpose:

```yaml
---
title: "..."
day: 24
time: "08:00"       # optional; default 08:00 Africa/Lagos
slug: "..."         # optional; auto-slugified from title
summary: "..."
categories: [a, b]
---
```


```python
def dummy_function(some: int, params: str) -> function:
    def inner():
        pass
    return inner
```

Future-dated posts don't publish until their time arrives. Drafts (`draft: true`) never publish.

### Injection table

For shared snippets — email addresses, repo links — there's a global table at `content/blog/_injections.yml`. Anywhere in a post I can write `\{{email}}` and it'll resolve to {{email}} at build time. Per-post frontmatter can override it locally.

## What to expect

Notes on backend systems, AI/ML as I learn it, occasional rants about tooling. Not on a schedule. When I have something worth writing about, it'll show up here.
